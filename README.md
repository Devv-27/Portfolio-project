# Portfolio CMS

A Spring Boot based Portfolio Management System.

## Features
- Portfolio website
- Project management
- Admin panel
- Spring Boot backend
- Maven
- HTML/CSS/JavaScript

## How to Run

### Requirements
- Java 17+
- Maven

### Run

```bash
git clone https://github.com/Devv-27/Portfolio-project.git
cd Portfolio-project
mvn spring-boot:run
